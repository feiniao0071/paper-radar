# Paper Radar 故障模拟结果（2026-09-30）

测试对象：cbdd167 修复后的重试与评估恢复逻辑。

新增 35 个模拟用例，使用真实 OpenAI SDK 和 httpx.MockTransport 注入故障；
不访问真实 API，不读取密钥，不发送飞书消息。sleep 被替换为等待时长记录。

| 场景 | 验证结果 |
| --- | --- |
| HTTP 408/409/429/500/502/503/504，连续失败 1、2、4 次后恢复 | 成功恢复；等待序列和调用次数正确（21 个用例） |
| HTTP 401/403/404 | 一次失败立即退出，不反复重试（3 个用例） |
| Retry-After 正常、超大、无效、负值 | 正常遵守等待，下限为本轮退避，上限 300 秒（4 个用例） |
| 连接错误、读取超时、读取错误 | SDK 包装异常后仍按策略恢复（3 个用例） |
| SSE 流提前结束，没有完成事件 | 丢弃残缺文本，重新请求并取得完整结果 |
| 持续 503 | 总共 5 次调用后停止，累计模拟等待 450 秒 |
| dry-run / resend-latest 遇到 AI 失败 | 无消息发送，磁盘状态字节保持不变（2 个用例） |

原有回归用例同时验证：连续两次评估失败仅提醒一次；论文保持 deferred，
当天不标完成；恢复后发送一次并记 sent，再次运行不重复发送；
503 耗尽重试后不切 JSON 模式重复一轮预算；流式读取中断能恢复。

运行命令：

```bash
.venv/bin/ruff check .
.venv/bin/pytest -q
```
